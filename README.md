## 2. Tested System Prompts (`prompts.html`)

1. **Modern UI Builder** — Enforces 60-30-10 color balance, WCAG AA contrast, real interactive states, and clean responsive spacing.
2. **Full-Stack Architecture** — Establishes TypeScript schemas, validation boundaries, and resilient loading/empty/error states first.
3. **Landing Page Copy + Code** — Combines jargon-free conversion copywriting with balanced typography and structured sections.
4. **Responsive Tailwind Layout** — Guarantees zero horizontal overflow, single-line controls, and consistent mobile-to-desktop grids.
5. **API Integration** — Implements typed fetch wrappers with `AbortController` timeouts, race-safe cancellation, and user-safe error recovery.

---

## 3. Debugging & Error Fixing Prompts (`debugging.html`)

1. **Fix Without Breaking Code** — Isolates root causes and restricts edits to the smallest minimal diff with zero regressions.
2. **Explain Stack Trace Simply** — Translates noisy runtime/compiler stack traces into plain-English cause, trigger condition, and fix.
3. **Refactor Messy AI Code** — Flattens nesting and extracts pure helpers while preserving identical APIs and UI behavior.
4. **Performance Optimization** — Targets re-render loops, sequential fetch waterfalls, and layout-thrashing animations.
